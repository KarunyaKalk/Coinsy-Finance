# AI Personal Finance System

**Tech Stack:** Python · JavaScript · Scikit-learn · FastAPI

An intelligent personal finance web app that predicts expense trends, promotes better financial habits, and provides interactive visual insights. Built with machine learning and a modern UI for proactive budgeting and savings management.

---

## 🚀 Overview

The **AI Personal Finance System** helps users understand their financial behavior through predictive analytics, smart reminders, and real-time dashboards. It analyzes spending patterns to forecast future expenses and provides actionable insights for better decision-making.

---

## 🎯 Key Features Implemented

### 1. Predictive Analytics

* Forecasts next month's spending based on current patterns
* Calculates projected savings automatically
* Analyzes spending velocity trends (increasing or decreasing)

### 2. Smart Reminders & Insights

* Real-time alerts when budget usage exceeds 80%
* Warnings about increasing spending trends
* Category-specific recommendations (e.g., meal planning tips)
* Positive reinforcement when savings goals are on track

### 3. Interactive Visualizations

* **Area Chart:** 7-day spending trend with gradient fill
* **Pie Chart:** Category breakdown with percentages
* **Bar Chart:** Category-wise detailed analysis
* Color-coded categories for quick interpretation

### 4. Intuitive User Experience

* Clean, modern UI with gradient accents
* Central dashboard for analytics and insights
* Simple expense entry form
* Real-time metrics (total spent, remaining budget, predictions)
* Recent transactions list

### 5. Proactive Financial Habits

* Budget tracking with visual progress indicators
* Savings goal monitoring
* Smart suggestions for reducing expenses
* Encouragement for positive financial behavior

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/ai-personal-finance-system.git
cd ai-personal-finance-system

# Create and activate virtual environment
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the FastAPI server
uvicorn main:app --reload
```

Then open your browser and visit:
`http://127.0.0.1:8000`
